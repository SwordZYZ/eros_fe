# iPad 磁力链接分享验收

本地 master 基线 `70b05223` 已包含 `d636c80b` 的生产修复。红色磁力按钮把所选种子的分享文本和按钮矩形一起传给系统。此前原生菜单及实际复制在 iPad 模拟器和真机各通过三轮。[历史验收](../artifacts/ios-share-fix-simulator-20261002/REPORT.md)

- 2026-11-19 使用 Flutter 3.47.3 和 iOS 27.2 复验。iPad 双栏与 iPhone 单栏模拟器均弹出系统分享菜单，实际复制后通过系统粘贴按钮核对全文。
- iPad Pro 11 英寸（M4），iPadOS 27.2（24B119）真机上，取消与重开、拷贝及接收文本的快捷指令通过。横竖屏和两种隐私遮罩状态下锁屏恢复后的种子入口与分享通过，四轮磁力值均与夹具一致。
- 其中一轮成功拷贝后，下拉刷新详情触发了 `SIGBUS`。11 月 20 日的独立 LLDB 对照没有复现同一崩溃，仍观察到解锁后刷新标题不更新，跳过系统分享也能出现。锁屏刷新仍需单独跟踪。原始和追加验收保存在本地分支 `codex/ipad-share-refresh`，结论提交为 `474a3b54`。

组件回归测试验证第二行红色按钮传给系统的磁力文本和按钮矩形。系统菜单、拷贝和快捷指令的结果来自上述实际设备及模拟器验收。[组件测试](../test/widgets/torrent_item_test.dart)
