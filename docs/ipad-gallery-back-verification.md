# iPad 第 3 项真机验证清单

使用出现过问题的 iPad，保持联网，确认左栏的漫画列表已加载、右栏初始为空。优先用平时出现问题的横竖屏、窗口模式和列表分组。若原构建仍可用，先录下原构建的表现，再用候选构建按同样步骤复测。每条路径开始前，将左栏滚到中段并等它停稳，记下最上方可见的漫画及其位置。有条件时录一段同时拍到两栏的屏幕录像。

1. **直接返回。** 从左栏点开一篇漫画。等右栏详情加载后，点右栏左上角的返回按钮。留意左栏是在打开详情时移动，还是在点返回时移动。
2. **换一篇再返回。** 重新将左栏滚到中段，先打开漫画 A，再从左栏点同屏的另一篇漫画 B。等右栏标题切换到 B 后，点右栏左上角的返回按钮。留意左栏在哪一步移动，以及返回后右栏显示空白、回到 A、还是出现其他结果。

### 两个独立的验收结果

- **左栏位置。** 两条路径都应停留在原列表或分组，最上方可见漫画及其垂直位置与操作前一致，并能继续滚动。
- **右栏与控制器。** 两次返回均应关掉当前详情并回到空白页。连接调试构建时由 agent 核对替换和返回时的日志，重点查 `ScrollController was used after being disposed` 或控制器未连接到滚动视图的异常。只有录屏时，可先确认右栏表现，控制器日志记为待查。

### 一次反馈所需的信息

- iPad 型号、iPadOS 版本、App 版本或构建号、横竖屏和窗口模式。
- 使用的标签或分组，两条路径各自是否跳顶、从哪一步开始、右栏最后显示什么。
- 有录屏时附上录像即可，能看到操作前后的左栏顶部和两次返回。

### 2026-11-19 USB 真机验证

iPad Pro 11 英寸（M4），iPadOS 27.2（24B119），使用独立开发版和联网列表。仅修复控制器所有权的构建仍会跳顶，横屏和竖屏均已复现。右栏正确回到默认占位图，调试日志没有滚动控制器释放或未连接异常。

临时诊断捕获到右栏 `/galleryPage → /empty` 后，Flutter 通过 `_handleStatusBarActions → CupertinoPageScaffold.handleStatusBarTap → ScrollController.animateTo` 让左栏回顶，一次记录的左栏列表偏移为 10552.0 → 0.0。用户另观察到滑至列表底部后有一次未回弹，卡片停在较高位置，其与跳顶的关系尚未确定。

实测这个事件在返回后约 350 毫秒到达。最终方案针对 iOS 双栏，在右侧漫画详情退出后 650 毫秒内拦截第一个会触发左栏回顶的状态栏动画。真机复测记录了四次拦截，延迟为 348–350 毫秒，右栏均回到默认占位图，用户确认左栏不再跳顶。用户感到轻微卡顿，判断不影响使用。真机反馈尚未单独确认主动点状态栏的结果，组件测试验证了普通回顶和后续主动回顶仍能执行。[分栏修复](../lib/widget/cupertino/split_left_scroll_scope.dart) · [组件测试](../test/split_left_scroll_scope_test.dart)

调试期间仍记录到远端阅读进度空列表异常、论坛头像请求 HTTP 403 和图片解码异常。滚动控制器释放、未连接或重复连接的日志均为零。

清理临时诊断后，模拟器回归在每个右栏返回后的约 350 毫秒注入真实格式的状态栏平台消息。直接返回的左栏偏移保持 830 → 830，替换详情后返回保持 1660 → 1660，两条路径的首个可点条目及屏幕位置一致，均无滚动控制器异常。组件测试、iOS 冷启动与设置返回冒烟，以及 14 项宿主测试均通过。[更新后的回归测试](../integration_test/ipad_gallery_back_test.dart)
