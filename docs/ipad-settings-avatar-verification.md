# iPad 设置页账号入口验证

## 修复前复现

以 `bef559f98dafad6ecf75414fc530df9e97e05bbc` 为测试基线。关闭安全模式，从 iPad 底栏进入「设置」，将窗口从高大于宽调成宽大于高，或旋转到横屏。账号入口随大标题消失。竖屏中将设置列表向上滚动至大标题折叠，也没有可点击的账号入口。

预期在展开态、滚动折叠态和宽窗口中，「设置」导航栏右侧始终只有一个可用的账号入口。登录后点击应打开现有账号操作，未登录时应打开登录页。安全模式应隐藏入口。

## iPad 真机清单

使用包含第 2 项修复的合并候选构建。记录构建提交、iPad 机型和 iPadOS 版本。先使用已登录账号和默认设置，确认设置页位于双栏的左栏。

- [ ] **竖屏顶部。** 进入「设置」并回到列表顶部。大标题可见，导航栏右侧只有一个头像。点头像应打开账号操作，点取消回到设置。
- [ ] **竖屏滚动。** 向上滚动，等「设置」变成小标题再点头像。头像仍应只有一个，点击仍打开账号操作。滚回顶部再检查一次。如果当前窗口能容纳全部设置项，可缩短窗口高度并保持高大于宽，再滚动。
- [ ] **跨过 1:1。** 设置页保持打开，将窗口从高大于宽调到宽大于高，再调回。也可用设备竖横屏切换验证。宽窗口的小标题右侧应始终只有一个头像，点一下能打开账号操作。调窄双栏左侧后再检查标题与头像都能看见。
- [ ] **未登录。** 在未登录的测试构建或测试资料中点右上角的默认账号图标，应进入登录页，返回后仍只有一个入口。

安全模式的隐藏与恢复已由组件测试覆盖。真机补验时，使用事先启用 `ehConfig.safeMode` 的独立测试资料，进入「设置」并跨过 1:1，确认两种窗口中都没有头像。当前「安全」页面没有该开关。

遇到不符时，记下对应步骤、窗口是宽还是高、标题是展开还是折叠，以及点按后的结果。一张截图或一段短录屏即可帮助复现。

### 历史、分组编辑和设置子页返回键

历史记录作为子页打开时，单列与双栏均使用窗口控件避让。分组编辑和设置子页复用同一组件。模拟器验证期间，相邻页面都使用避让按钮时，Cupertino 导航过渡会在 Hero 浮层中构建按钮。共享组件现在显式使用当前导航栈的 `maybePop`，保留系统返回和页面自己的退出规则。

未登录时，E-Hentai 设置页仅展示与账号无关的项目，进入时跳过额度请求。专项用例使用本地分组、未登录状态，并替换更新检查和快捷搜索的 WebDAV 同步。未替换同步的对照在无 WebDAV 配置时出现 `No host specified in URI /fehviewer/search/`，属于快捷搜索的初始化路径。

复测用例为 `integration_test/ipad_subpage_back_test.dart`。默认以 540 pt 单列冷启动，添加 `--dart-define=IOS_IPAD_SUBPAGE_SPLIT=true` 以 1030 pt 双栏冷启动。测试从真实页面点入分组编辑及各设置菜单，对比 UIKit 边距并点按返回。历史页使用应用的命名路由进入。

2026-11-21 在 iOS 27.2（24B8117）iPad 模拟器上运行 Debug，**540 pt 单列和 1030 pt 双栏各 13/13 通过**。覆盖历史、分组管理、分组编辑、设置的八个一级菜单，以及栏目设置和快捷搜索。两轮均从相应宽度冷启动。控制台日志和构建证据位于本地缓存清单所列的 `subpage-back-single-v2`、`subpage-back-split-v2` 轮次。

### iPhone 返回键位置复审

Cupertino 会给显式 `leading` 应用起始内边距。现仅在 UIKit 对返回键这一侧提供正边距时传入自定义返回键，零值或空值时由原生 Cupertino 导航栏生成返回键。组件测试以未经包装的导航栏为基准，验证 UIKit 返回空值和零值时按钮横坐标一致，并验证窗口变更时正边距可应用和撤销。

2026-11-21 的 iOS 27.2 模拟器回归中，iPhone 17e、540 pt iPad 单列和 1030 pt iPad 双栏分别通过 13/13 条返回路径。iPhone 的原生渠道返回空值，13 条路径全部使用系统自动返回键。

iPad 模拟器的详情与画廊返回、阅读器工具栏与阅读设置返回、设置头像与登录往返也通过。390 pt 阅读器窗口的 UIKit 左右边距均为 9.5 pt。

同一源码及依赖锁构建的签名 Profile 包 `1.9.2 (575)` 已覆盖安装到 iPad Pro 11 英寸（M4），iPadOS 27.2（24B119）。CoreDevice 回查确认启动的是 575，点按结束后仍是同一进程。

**575 真机点按通过。** 使用者在红绿灯可见的非全屏窄窗中确认，从画廊左上进入的历史记录、单个分组的编辑页、设置中的布局与栏目设置共四页，返回键均与红绿灯分开，且能点回上一页。
